## Sobre

Engenheiro de Dados na **[Dati](https://dati.digital)**, consultoria em Blumenau. Construo a parte que ninguém vê: a ingestão que roda de madrugada, a transformação que reconcilia fontes que discordam entre si e a API que entrega o número certo na tela do cliente.

Trabalho majoritariamente em **AWS com CDK** — infraestrutura como código, Lambda, S3 — e cada vez mais com **agentes de IA** aplicados a processos reais: extração e validação de documentos, automação de propostas, assistentes que consultam dados internos.

|  |  |
|---|---|
| **Papel** | Engenheiro de Dados — projetos de consultoria |
| **Domínios** | Pipelines de dados · IA generativa aplicada · automação de processos |
| **Formação** | Sistemas de Informação — FURB |
| **Base** | Blumenau, Santa Catarina, Brasil |
